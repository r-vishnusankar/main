# Home Preview Images

Place your own images in this folder to replace the default Unsplash images on the homepage.

## Image Slots

| File name               | Used in                        | Recommended size |
|-------------------------|--------------------------------|------------------|
| `homepage-banner.jpg`   | Homepage Banner purpose card   | 800×450 (16:9)   |
| `product-card.jpg`      | Product Card purpose card      | 600×800 (3:4)    |
| `instagram-post.jpg`    | Instagram Post purpose card    | 600×600 (1:1)    |
| `sale-promo.jpg`        | Sale Promo purpose card        | 800×450 (16:9)   |
| `email-header.jpg`      | Email Header purpose card      | 900×300 (3:1)    |
| `festival.jpg`          | Festival / Event purpose card  | 600×600 (1:1)    |

## How it works
- If a file exists here, it is used automatically.
- If the file is missing, the app falls back to a relevant Unsplash photo.
- Supported formats: `.jpg`, `.jpeg`, `.png`, `.webp`
- After adding images, **refresh the page** (no rebuild needed).
